# Modifold

Modifold is an open web platform for publishing, discovering, and managing Hytale mods.

Our goal is to build a clean, community-first ecosystem where creators can share their work, players can find trusted mods, and the wider Hytale modding scene can grow on open infrastructure.

## Contributing

Small, focused improvements are welcome: bug fixes, UI polish, performance work, accessibility, translations, API cleanup, documentation, and deployment hardening.

Before contributing, please keep changes scoped and easy to review. If you want to work on a larger feature, open an issue or discussion first so the direction can be agreed on.

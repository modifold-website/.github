# Modifold

Modifold is an open-source platform for **Hytale mods**: upload, discover, download, discuss, and improve community content together.

We build Modifold as a fan-driven project with a focus on creators, moderation quality, and long-term reliability.

## Development Flow

- `develop` — staging branch
- `main` — production branch

Typical release path: `develop` -> testing -> `main`.

## Open Source

Contributions, fixes, and improvements are welcome.

- UX/UI improvements
